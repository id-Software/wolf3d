## Purpose and scope

R1.1 identifies where every source file, asset and external dependency comes from, and establishes which content can legally be redistributed. It is documentation and inventory only. It does not refactor code, remove legacy files, or claim legal release readiness.

In scope:

- Source-code inventory (active `src/`, historical `WOLFSRC/`, tests, tools, scripts);
- Asset and data-file inventory (tracked binaries, generated code, external data);
- Dependency and licence inventory (third-party libraries, build tools, SDKs);
- Licence classification with redistribution status;
- Engine/content coupling findings for future R1.2–R1.5 work.

Out of scope:

- R1.2 symbol/branding/text/audio audit;
- R1.3 engine vs game boundary implementation;
- R1.4 legacy-content isolation;
- R1.5 distributable-asset manifest;
- Any code modification, asset deletion or redistribution.

### 4.2 Source-code vs game-content distinction

- **Source code licensing:** The active engine port in `src/` is GPL-2.0-only per project statement. This is a project assertion, not an independent legal review. Historical Wolfenstein source was released under GPL by id Software (per official iDoom source-release README), but this project's historical snapshot also retains a limited-use notice.
- **Game-content rights:** Commercial WL6 data, SIGNON artwork, music, sounds, trademarks and other game content are entirely separate from the engine source licence. These are proprietary and cannot be redistributed. The repository does not contain them (they are external/user-supplied).
- **Third-party code:** emu8950 is MIT-licensed and retains its own terms. SDL3 is zlib-licensed. Neither is GPL, so both require notice preservation but do not impose GPL copyleft on the combined work beyond what the active source already requires.

## 5. Engine/content coupling findings

### 5.1 Wolfenstein-specific references in active source

The active `src/` tree contains numerous Wolfenstein-specific identifiers:

- **Hardcoded resource names:** `VSWAP.WL6`, `GAMEMAPS.WL6`, `MAPHEAD.WL6`, `AUDIOT.WL6`, `AUDIOHED.WL6`, `VGADICT.WL6`, `VGAHEAD.WL6`, `VGAGRAPH.WL6` — referenced in `ID_CA.c` and `main.c`.
- **Map indices:** 60 WL6 map slots, fixed 64×64 planes, 64 doors — hardcoded in `ID_MAP.h`, `WL_GAME.c`, `WL_ACT1.c`.
- **Resource pages:** Fixed VSWAP page numbers for walls, sprites, etc. — referenced throughout `WL_DRAW.c`, `WL_SCALE.c`, `WL_RENDER.c`.
- **Game identity:** Episode/level names, boss types, weapon names, enemy types — defined in `WL_DEF.h`, `WL_ACT2.c`, `WL_STATE.c`.
- **Audio:** AdLib/OPL music and sound effect identifiers tied to WL6 audio chunks — `ID_SD.c`, `WL_SOUND.h`.
- **UI/branding:** Menu text, HUD elements, high-score names — `WL_MENU.c`, `WL_TEXT.c`, `WL_HIGHSCORES.c`.
- **SIGNON artwork:** Referenced via `SIGNON.OBJ` historical object; not incorporated in active title path per `docs/LICENSING.md`.
